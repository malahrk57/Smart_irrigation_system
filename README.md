# Smart_irrigation_system

Agriculture requires efficient water management to improve cropproductivity and reduce water wastage. In this project, I proposed an IoT-Based embedded system for smart irrigation and real-time soil moisture monitoring to improve irrigation efficiency. In this system, an ESP32 Dev Board microcontroller is used along with a Soil Moisture sensor, DHT22 (Temperature and Humidity Sensor), and a raindrop sensor to monitor field conditions continuously.
The system is supported by Edge-AI for predicting what should be the status of the water pump in certain conditions. The system automatically checks the soil moisture level and other parameters and controls the water pump through a relay module whenever irrigation is required. This device helps in supplying water only when needed. This reduces water wastage and improves crop productivity. A 16x2 I2C LCD module is also used to show the sensor readings directly in the field for easy monitoring.The system is connected with the Blynk IoT platform, which allows users to monitor soil moisture and other environmental parameters in real-time using a web dashboard or mobile phone. Thesystem is simple, cost-effective, and energy-efficient, making itsuitable for real-time agriculture applications and helping farmers adopt modern smart irrigation techniques.
In addition to real-time monitoring and automated irrigation control, the system also supports sensor data logging through USB serial communication. The collected values of soil moisture, temperature, humidity, rainfall status, and pump status are stored in CSV format on a connected computer. This feature enables historical data analysis, system performance evaluation, and future machine learning model development.
